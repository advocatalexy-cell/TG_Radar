Курс дал не теорию, а рабочий инструмент. За две недели я довел до готовности Radar – мультиагентный мониторинг Telegram-каналов про ИИ в праве, который сам собирает сообщения из ~85 источников, отсеивает шум и публикует дайджест в канал.

Самое полезное – подход «сначала описание, потом код». Когда сформулировал проблему, пользователя и минимальный функционал до начала разработки, Claude Code сразу стал предлагать точные решения, а не общие заготовки.

Освоил новый навык – доводить проект от локального прогона до публичного репозитория: GitHub CLI, коммиты, README со скриншотами, скилл для передачи проекта коллегам. Раньше публикация кода была для меня отдельным барьером – теперь это несколько понятных команд.

Впервые сам развел архитектуру на два независимых звена – VPS и облачный Routine – и объяснил, почему нельзя иначе: одно физически не достучится до Telegram, другое не даст мультиагентной оркестрации. Раньше я бы искал единое решение, а не признавал ограничения инфраструктуры как данность.

Работа с Claude Code изменилась от разовых запросов к диалогу с контекстом: скиллы, память, task-лист позволяют не пересказывать проект заново на каждом шаге. Инструмент стал похож на коллегу, который помнит структуру репозитория и предлагает следующий шаг, а не только отвечает на конкретный вопрос.

Результат курса – рабочий MVP на GitHub: пайплайн из пяти шагов, два аналитических агента, скилл для развертывания проекта и скилл для адаптации контента под соцсети. Проект уже проходил полный end-to-end прогон и работает по расписанию.
